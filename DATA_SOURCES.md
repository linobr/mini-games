# Atom-Labor data source

The periodic-table metadata in `src/periodic-table-data.js` is a reduced
derivative of **Bowserinator/Periodic-Table-JSON**:

- Source: https://github.com/Bowserinator/Periodic-Table-JSON
- Data license: Creative Commons Attribution-ShareAlike 3.0 Unported
- Fields used: atomic number, symbol, atomic mass, period, group, periodic-table
  position, electron shells and electron configuration.
- German display names were added for this project.
- Only elements 1–118 are included.

The Atom-Labor application code itself is maintained separately from this data
attribution. See the upstream project for the original dataset and its full
license text.
